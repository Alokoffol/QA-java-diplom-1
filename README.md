# QA Java Diploma Project

## Технологии
- Java 11
- JUnit 4.13.2
- Mockito 4.11.0
- JaCoCo 0.8.8
- Maven 3.9.0
- Allure Report

## Запуск тестов
```bash
mvn clean test
```

## Структура проекта
